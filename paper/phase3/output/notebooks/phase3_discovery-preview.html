This notebook records the constructive route to

[ X_t=X_0+t+W_t, Z_t=Z_0!((+i)(X_t-X_0)). ]

It is deliberately different from the original Phase 3 verification notebook. We start from design requirements, discover the log-polar map, derive its Itô dynamics in two ways, identify the noise-rank obstruction, and then test every claim numerically.

The notebook generates the figures and tables used by the paper. All randomness is seeded. Analytic results are proved in the paper; simulation is used for verification and geometric explanation.

1. Design requirements

We want a complex variable that satisfies four requirements:

  1. it uses the same single Brownian driver as (X);
  2. both radius and angle are stochastic;
  3. the scalar state is recoverable at each time;
  4. the induced complex random walk has an exact finite-step rule.

A useful starting point is not to guess (Z) directly. Write

[ A_t=R_t=a(X_t), _t=b(X_t), Z_t=(A_t+i_t). ]

Any deterministic choices of (a) and (b) preserve the one-driver constraint automatically. Injectivity can then be designed into (a).

2. The simplest smooth choice

The globally smooth affine choice

[ a(x)=R_0+(x-X_0), b(x)=_0+(x-X_0) ]

is enough. It yields

[ Z_t=Z_0e^{c(X_t-X_0)},c=+i. ]

If (), the radius is strictly monotone in (X), giving

[ X_t=X_0+. ]

When also (), eliminating (X_t-X_0) gives the deterministic support relation

[ _t-_0 =, ]

the equation of a logarithmic spiral.

3. Exact recovery and exact random-walk steps

Every scalar grid increment

[ X_n=,t+,W_n ]

induces the exact update

[ Z_{n+1}=Z_n(c,X_n). ]

The same scalar increment controls radial scale (e^{X_n}) and rotation (X_n). This is an exact product identity at grid points, not an Euler approximation.

4. Itô dynamics, derived twice

For (F(x)=Z_0e^{c(x-X_0)}), (F’=cF) and (F’’=c^2F). Scalar Itô gives

[ =(c+12c22)dt +c,dW_t. ]

Independently, (dA=,dt+,dW) and (d=,dt+,dW). Applying the two-dimensional Itô formula to (e^{A+i}) gives the same drift:

[ +i +(2-2)^2 +i^2 =c+12c22. ]

In [7]:
Code 
alpha_s, beta_s, mu_s, sigma_s = sp.symbols(
    "alpha beta mu sigma", real=True
)
c_s = alpha_s + sp.I * beta_s
direct_drift = sp.expand(c_s * mu_s + sp.Rational(1, 2) * c_s**2 * sigma_s**2)
polar_drift = sp.expand(
    alpha_s * mu_s
    + sp.I * beta_s * mu_s
    + sp.Rational(1, 2) * (alpha_s**2 - beta_s**2) * sigma_s**2
    + sp.I * alpha_s * beta_s * sigma_s**2
)
drift_difference = sp.simplify(direct_drift - polar_drift)
print("Direct Itô drift:", direct_drift)
print("Polar Itô drift: ", polar_drift)
print("Difference:       ", drift_difference)
assert drift_difference == 0
Direct Itô drift: alpha**2*sigma**2/2 + I*alpha*beta*sigma**2 + alpha*mu - beta**2*sigma**2/2 + I*beta*mu
Polar Itô drift:  alpha**2*sigma**2/2 + I*alpha*beta*sigma**2 + alpha*mu - beta**2*sigma**2/2 + I*beta*mu
Difference:        0

The bilinear and Hermitian complex brackets are different:

[ d[Z,Z]_t=c22Z_t^2,dt, d[Z,]_t=|c|22|Z_t|^2,dt. ]

The first is complex and may rotate or cancel; the second is real and nonnegative. The next experiment compares discrete quadratic-variation sums with their Itô-integral targets along one fixed Brownian path.

5. The covariance-rank obstruction

The log-polar diffusion vector is

[ \[\begin{pmatrix}\alpha\\\beta\end{pmatrix}\]

. ]

Hence

[ \[\begin{pmatrix} [A,A]_t &[A,\Theta]_t\\ [\Theta,A]_t&[\Theta,\Theta]_t \end{pmatrix}\] = ^2 \[\begin{pmatrix}\alpha\\\beta\end{pmatrix} \begin{pmatrix}\alpha&\beta\end{pmatrix}\]

, ]

an outer product of rank one. More generally, if (F:RR^2) is (C^2), then

[ dF(X_t)=+F’(X_t)dW_t, C_t=2F’(X_t)F’(X_t), ]

so (C_t). This statement concerns instantaneous noise rank, not the apparent dimension of a plotted path.

7. Strong convergence of Euler–Maruyama

The induced complex SDE is linear:

[ dZ_t=Z_tdt+Z_tdW_t, =c+12c22, =c. ]

We couple every resolution to the same finest Brownian paths and compare terminal Euler–Maruyama values with the exact exponential solution. The predicted generic strong order is (1/2).

In [11]:

nu_complex = C * SIGMA
n_em_paths = 10_000
n_fine = 512

8. Why the literal real-axis polar form fails globally

The direct complex image (X_t+i0) has radius (|X_t|) and angle (0) or () away from zero. Before

[ _0={t:X_t=0}, ]

Itô’s formula applies to (|X_t|). At a zero, the logarithm is singular and the angle jumps between the two rays.

The correct global identity for standard Brownian motion is Tanaka’s formula

[ |W_t| =_0t(W_s),dW_s+L_t0, ]

where (L_t^0) is symmetric local time at the origin.

9. Representation hierarchy

The word representation hides several non-equivalent requirements:

  • a deterministic image only needs (Z_t=F(X_t));
  • a state-injective embedding also permits pointwise recovery;
  • pathwise recovery may use the entire lifted path, such as an unwrapped angle;
  • equality as a planar stochastic model additionally requires the correct two-dimensional local covariance.

The logarithmic spiral satisfies the first three when (), but cannot satisfy the fourth for a rank-two target.
